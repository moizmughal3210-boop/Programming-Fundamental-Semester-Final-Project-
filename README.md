# IST Admission Portal (C++)

## 📌 Project Overview
The **IST Admission Portal** is a console-based and GUI effects application developed in **C++** as a final project.  
It simulates an admission management system for IST, allowing users to manage student admissions efficiently through a simple and user-friendly interface.

This project demonstrates the practical use of **C++ programming concepts** such as file handling, functions, structures, and conditional logic.

---

## 🎯 Objectives
- Automate the admission process
- Store and manage student records
- Provide a menu-driven system for users
- Apply core C++ concepts in a real-world scenario

---

## ⚙️ Features
- Student registration
- Display student records
- Search student details
- Update admission information
- Delete student records
- File handling for data storage
- Menu-driven console interface
